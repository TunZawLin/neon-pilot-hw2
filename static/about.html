Pretrained intelligence. Human instinct.

NEON PILOT is a local Open Source Software homework demonstration of pretrained model inference. We did not train or retrain a model.

What uses machine learning?

Google’s MediaPipe Hand Landmarker float16 model, version 1, detects a hand and estimates 21 landmarks from webcam frames. The @mediapipe/tasks-vision runtime is pinned to 0.10.18 and uses CPU inference in a dedicated browser worker. One frame is processed at a time, at up to approximately 15 frames per second, independently of Canvas rendering.

What uses ordinary rules?

Mirroring, palm-center steering, smoothing, pinch detection, lasers, cooldowns, enemy motion, difficulty, scoring, collisions, and lives are ordinary JavaScript rules. Pinch distance is divided by palm size with aspect-ratio correction. A smoothed ratio below 0.32 for two frames engages firing; above 0.46 releases it. The HUD shows this ratio, average inference latency, and completed inference frequency. These are performance indicators, not model accuracy scores.

Privacy & safety

Camera access begins only after Enable Camera. Frames stay in memory on your device. There is no frame-upload endpoint, recording, third-party runtime request, or cloud service. Disable Camera or leave the page to stop the stream. Losing the hand, changing controllers, switching tabs, or losing focus pauses the game; resuming is explicit. Release a pinch or Space after resuming before firing again.

MLOps connection

Versioning: Runtime and model URLs are pinned and SHA256 hashes are recorded in assets.lock.json. Setup verifies hashes and refuses changed files. Dependency versions and asset licenses are documented.

Evaluation: Evaluate real hand detection and pinch precision/recall across lighting, backgrounds, hand sizes, camera angles, skin tones, left/right hands, and laptops. Record false activations per minute, tracking loss, recovery time, and latency percentiles. Synthetic unit tests validate geometry rules; they do not establish model accuracy.

Monitoring: The local flight panel exposes average model inference time, inference frequency, pinch ratio, and tracking loss. The FastAPI health endpoint reports service and asset readiness. No telemetry leaves the browser.

Future improvement: Use a consent-based labeled gesture evaluation set, tune thresholds or add personal calibration, compare pinned model candidates, test CPU latency, then roll back if gesture reliability regresses. A learned gesture classifier would need a separate training, validation, and versioning workflow. Public deployment is outside this homework’s scope.

Camera-free runtime check

Loads the real local pretrained model and runs CPU inference on a synthetic blank frame. This never opens the camera and does not establish real hand-tracking accuracy.

Sources & licenses

MediaPipe runtime and Hand Landmarker model: Google, Apache License 2.0. The source URLs, sizes, hashes, and local license are listed in the bundled license, assets.lock.json, and ASSETS.md in the project folder. Game artwork is original Canvas/CSS; no external images or fonts are used.

Recommended: current Chrome or Edge on localhost, a webcam, one visible hand, and even lighting. Actual camera performance depends on your CPU, browser, and environment.
